## 用最简单的话理解 LLM 与 Agent

大语言模型（LLM）根据已有上下文逐步生成下一个 token。它擅长语言、代码和模式归纳，但流畅回答不等于有证据，模型也可能编造、漏看条件或不稳定地处理冲突指令。模型输出只是建议，不会自行获得操作权限。

Agent（智能体）是把 LLM 接入一个能够观察、调用工具、读取执行结果并继续工作的程序。典型闭环是：

```text
用户目标 → LLM 提出计划或工具请求 → 程序检查权限并执行
    ↑                                      ↓
    └──────── LLM 读取工具结果后继续或结束 ─┘
```

RAG 从外部资料中找当前任务的证据；记忆保存过去的信息供后续会话使用；工具调用查询事实或改变外部状态。CoT 是模型生成的推理文本，可能不完整或不忠实，不能单独作为安全保证。真实安全边界还依赖工具白名单、参数检查、执行权限和环境状态验证。

## 读安全论文时先问四件事

1. 攻击者能控制什么输入、数据或工具？不能控制什么？
2. 风险进入 Agent 的哪个环节：训练、检索、记忆、计划还是工具执行？
3. 论文用什么可观察结果判定安全？只看语言回答，还是检查动作和环境状态？
4. 论文没有验证什么？它和你自己的问题究竟差在哪个可测量条件？
